# Беклог

- [ ] Добавить выбор количества знаков после запятой при редактировании валют: сейчас доступно только 2 знака, нужны другие варианты точности.
- [ ] Исправить редактирование иерархии счетов в разделе «Расходы»: сейчас нельзя редактировать иерархию дальше первого уровня. Обеспечить редактирование на всех уровнях вложенности, например для счёта «Автомобиль» и его потомков.
- [ ] Добавить кнопку для скрытия и показа балансов счетов.
- [x] В строке транзакции размещать теги рядом с описанием, не перенося их на вторую строку, если в первой достаточно места. Сделать каждый тег кликабельным: по нажатию показывать транзакции с этим тегом.
- [ ] Сделать общую страницу 404 для отсутствующих счетов, транзакций и других несуществующих адресов: понятное сообщение и ссылка для возврата в приложение; отдавать HTTP 404 вместо ошибки сервера или пустой страницы.
- [ ] Для счетов типа «Доход» показывать списания со счёта как положительные поступления в списке транзакций и отображать итоговый баланс доходного счёта положительным. Изменить только представление сумм, сохранив знаки проводок в учёте.
- [ ] Добавить возможность задавать и изменять время транзакции вместе с датой — как в UI, так и через MCP.
- [x] Исправить отображение больших сумм в окне редактирования транзакций: показывать полную десятичную запись без экспоненциального формата (например, `12000000` вместо `1.2e+07`), сохраняя точность суммы.
- [ ] В строке транзакции сделать ссылку на второй счёт якорной: при переходе открывать второй счёт и прокручивать список к этой же транзакции.
- [x] Исправить сворачивание ветки счетов в списке слева: сейчас нажатие на элемент сворачивания обновляет страницу, как при клике по счёту. Нажатие должно сворачивать или разворачивать ветку без перехода на счёт и обновления страницы.
- [ ] Добавить в MCP `get_currency_rates` необязательный параметр `date` (YYYY-MM-DD) для запроса курсов ЦБ, действующих на указанную дату, из данных сервиса. Без даты сохранить текущее поведение. Возвращать валютную пару, курс, источник и дату действия курса; если исторических данных нет, явно сообщать об этом, не подменяя их актуальным курсом. Пример: USD/RUB на 27.11.2018 для пересчёта валютной транзакции.
- [x] Добавить редактирование валют в админке: название и обозначение. Код и точность существующей валюты неизменны.
- [x] Добавить привязку курсов к валютам справочника: две валюты для каждой пары и источника, управление в админке.
- [x] Добавить в транзакцию отдельное поле «Комментарий» для дополнительной информации, которая нужна, но не должна попадать в «Описание» (например, расчёты курсов, данные исходной выписки и уточнения). Описание оставить кратким назначением операции.
- [x] В транзакциях, где валюта счёта списания отличается от валюты расходного счёта, показывать подходящий курс на дату транзакции и автоматически пересчитывать по нему второе поле суммы. Если пользователь переопределил вторую сумму вручную, не перезаписывать её автоматическим расчётом.
- [x] Добавить memory в MCP: агенты могут сохранять, читать и обновлять полезную информацию прямо в сервисе и использовать её в следующих сессиях. Хранить информацию отдельно для каждого пользователя.
